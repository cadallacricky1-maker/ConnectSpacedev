# ConnectSpace Website

A modern, responsive website for ConnectSpace - a collaboration and communication platform.

## 📋 Project Structure

This website is built with 9 main sections, each mapped to GitHub Issues #1-#9:

### Website Pages/Sections

- **Is1 (Home)** - `index.html`
  - Hero section with call-to-action
  - Welcome message and brand introduction

- **Is2 (About)** - `about.html`
  - Company story and mission
  - Team values and background information

- **Is3 (Features)** - `features.html`
  - Key features and benefits showcase
  - 6 main feature highlights with descriptions

- **Is4 (Portfolio)** - `portfolio.html`
  - Case studies and project showcase
  - Client success stories and implementations

- **Is5 (Testimonials)** - `testimonials.html`
  - Customer reviews and feedback
  - 5-star testimonials from satisfied clients

- **Is6 (Pricing)** - `pricing.html`
  - Service tiers and pricing plans
  - Starter, Professional, and Enterprise options

- **Is7 (Contact)** - `contact.html`
  - Contact form and contact information
  - Email, phone, and physical address details

- **Is8 (Blog)** - `blog.html`
  - Blog posts and news articles
  - Latest updates and insights

- **Is9 (Footer/Navigation)** - `css/styles.css` & `js/main.js`
  - Navigation menu (in navbar)
  - Footer with social links and copyright

## 🚀 Getting Started

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, Edge)
- No additional dependencies required

### Installation

1. Clone the repository:
```bash
git clone https://github.com/cadallacricky1-maker/ConnectSpacedev.git
cd ConnectSpacedev
```

2. Switch to the website-structure branch:
```bash
git checkout website-structure
```

3. Open any HTML file in your browser:
```bash
# Option 1: Double-click the file
open index.html

# Option 2: Use a local server (Python)
python3 -m http.server 8000
# Then visit http://localhost:8000
```

## 🔧 Customization

### Updating Content

1. **Colors**: Edit CSS variables in `css/styles.css` (`:root` section)
2. **Text**: Update HTML files directly
3. **Images**: Add image elements in portfolio and blog sections
4. **Forms**: Customize contact form in `contact.html`

### Adding New Pages

1. Create new HTML file
2. Copy navigation from existing pages
3. Add unique content section
4. Update navigation links across all pages

## 🚀 Deployment

### Deploy to GitHub Pages

1. Push to main branch:
```bash
git add .
git commit -m "Deploy website"
git push origin main
```

2. Enable GitHub Pages in repository settings:
   - Go to Settings > Pages
   - Select main branch as source
   - Your site will be live at: `https://cadallacricky1-maker.github.io/ConnectSpacedev/`

### Deploy to Other Platforms

- **Netlify**: Connect GitHub repo, select main branch
- **Vercel**: Import project, deploy automatically
- **Traditional Hosting**: Upload files via FTP
